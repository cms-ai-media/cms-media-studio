最後一哩：正片、上架資料與宣傳短片

頻道主看完整片審查版、按下「放行」，製作就結束了嗎？還沒。從放行到影片公開、再到之後幾天， 還有一長串容易出錯的小事：哪一版是母片、片名怎麼寫、說明欄的章節時間、封面的尺寸、宣傳短片、相關影片的連結…… 這一篇講這最後一哩怎麼盡量交給程式，但把幾個關鍵的按鈕留給人。

正片：不重新壓縮

正片（上傳用的母片）就是頻道主放行的那一版審查版，畫面與聲音逐位元相同，只重新封裝，不重新壓縮、不重新鋪配樂。 做之前確認幾件事：已經放行、本機跟控制台一致、出片前檢查通過、原片用量在上限內，以及——放行時他看的就是這一版。

最後這條是踩過坑才加的：頻道主放行之後指出一個讀音錯誤，更正後審查版出了新的一版。這時候正片該用哪一版？ 現在控制台按放行時會記下當時看的版號；版號不一樣，程式就停，要寫明原因才能繼續，兩版的差別自動列出來寫進紀錄； 控制台也會提醒他「之後又出了新的一版」，他看過再按一次。做完之後再驗：封包雜湊相同、整支解碼一次沒有錯誤、格數、長度、響度、峰值。

放行按鈕本身也改過一次。原本同一顆按鈕再按一次會問「要取消放行嗎？」，預設是「確定」——他就這樣不小心取消過一次。 現在放行之後變成一個綠色的「✓ 已放行」標籤，取消是旁邊另一顆小按鈕，問的時候兩個選項寫明「保持放行／取消放行」，預設保持。

上架資料：先自己檢查一遍

上架資料是一個資料夾：正片、封面（照 A/B 測試的順序）、片名、說明欄、標籤、置頂留言。內容由程式組出來，再逐項檢查：

  • 片名 1–100 字；頻道的格式是四段：「封面大字｜這一集在講什麼｜English title｜中文看世界」，大約 65 到 85 字。第一段要跟封面上的大字一模一樣——頻道列表上只看得到兩行，封面和片名開頭要讀起來像同一句話。
  • 說明欄 5000 字內、標籤 500 字內；章節時間從 0:00 開始，每段至少 10 秒（片頭動畫算在第一段裡）。
  • 封面 16:9、至少 1280×720、2 MB 以內、三張解析度相同。超過 2 MB 的另轉一份合規的，原圖不動。
  • 說明欄裡的原片出處、講者、配樂與授權由資料組出來，不手寫。

封面的 A/B 測試最多三張，順序由頻道主在控制台排。有一個小規矩：程式寫的說明「為什麼選這張」不寫組號—— 他會重新排順序，寫了組號就會對錯組。

宣傳短片

每一集配三支左右的直式宣傳短片，從正片裡剪、或由頻道主寫腳本。這部分累積的規則最多，幾乎每一條都是看完一版之後說的：

  • 不要對觀眾說「EP1、EP2」。那是我們內部的編號，觀眾不懂；結尾說片名。
  • 動物的聲音要在。旁白進行時，公鹿的叫聲照樣墊著。
  • 畫面要填滿直式的框，不要上下留黑邊或模糊底；用影片，不用靜態照片；橫的寬鏡頭在直框裡用慢慢橫搖的方式看完。
  • 單集的宣傳短片 60 秒以內，結尾只說這一集的片名，不加頻道口號；故事停在哪裡就停在哪裡，不用加速去塞。
  • 系列的宣傳短片要從整個系列取材——海岸、森林、地熱、瀑布、荒漠——每個鏡頭都要有東西在動，要有人的味道。
  • 短片的開頭第一秒是封面，所以封面的大字是逐字量出位置、跟影片的開頭疊在一起的。

還有兩件 API 做不到、只能在 YouTube Studio 裡做的事：每支短片的「相關影片」都要連到正片（正片公開之後立刻設）， 以及短片的縮圖——用 API 設定回報成功，Studio 裡卻還是自動截的畫面，最後改成在 Studio 的編輯頁面上傳。

公開之後

影片公開之後，還有幾件事要在當天做完：宣傳短片的相關影片連到正片、封面的 A/B 測試開始跑、控制台的狀態改成「已公開」。 之後的幾天，影片的表現會出現在控制台的「YouTube 成績」分頁——它的用途是看技術一代一代的變化，不是追觀眾的口味， 下一篇專門講它。
