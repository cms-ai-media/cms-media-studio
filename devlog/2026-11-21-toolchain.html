工具清單：一集節目背後用了哪些模型與工具

照製作的順序排。除了標明的雲端服務，運算都在家裡一台有顯示卡的 Windows 電腦上跑；AI 助手是 Claude（Claude Code 與桌面版）， 負責寫程式、寫稿、跑製作、回報。

步驟用什麼備註
立案、審稿、決定控制台：Claude Artifact 頁面＋共享資料庫平板可用；每一筆寫入帶版本號
本機值班Claude 桌面版的排程任務每 30 分鐘看一次有沒有新的交辦
大檔素材匣Google Drive 資料夾小檔直接傳到控制台
下載來源影片yt-dlp參考讀音只抓需要的那幾秒
英文逐字稿影片自帶字幕；沒有就用 faster-whisper每一句的時間可以在控制台點
寫稿頻道主的大綱或初稿（有時先經 ChatGPT）＋Claude程式產生製作腳本，逐字比對初稿
旁白配音F5-TTS（聲音複製，本機）頻道主本人的參考音
讀音rjieba、pypinyin、自訂破音字字典、英文念法表跟姊妹頻道共用
聽寫驗收與字幕對時faster-whisper（small／medium）音量另外量，辨識不全信
音高、長度、頻譜Praat（parselmouth）挑語氣、查音節數
版型設計Claude Design交回 HTML／CSS，原檔不動
算圖與排字無頭 Chrome、Playwright、瀏覽器的 Intl.Segmenter引擎與控制台用同一份排字程式
圖解與章節地圖網頁圖解＋推拉鏡頭；NASA Worldview／GIBS 衛星圖公有領域影像
示意動畫Python＋Pillow 逐格畫「簡化示意，比例不照實」
實拍素材Pexels、美國國家公園管理局、NASA、土地管理局、維基共享資源授權各自不同，見出處那一篇
讓照片動起來LTX 影片模型（ComfyUI，本機）只在本機跑，跟另一個頻道排隊用顯示卡
早期的生成圖本機 ComfyUI現在是最後手段
合成、混音、響度ffmpeg旁白 −17、原音 −18 LUFS，峰值 −1 dBTP
配樂YouTube 音效庫、CC BY 曲目曲庫清單登記授權與 credit
宣傳短片自寫的直式短片引擎（同一套聲音與字幕）封面與開頭逐字對齊
上傳與上架YouTube Data API（私人上傳）、YouTube Studio相關影片與短片縮圖只能在 Studio 設
成績追蹤YouTube Data API＋YouTube Analytics API只讀；每次存新快照
